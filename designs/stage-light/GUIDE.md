# stage-light 设计卡指南

一句话：与 stage-full **共用同一个折叠机制**，但只开两页内板、少一层道具、没有吊灯与焦点光；
转折靠一个**持续存在的关键纸卡**和它自身的空间位移来完成，而不是翻页式幻灯片。
§3 是一段 16 秒的示范编排，**不是口播时间证据**：2 / 6 / 11 / 15 秒是可读检查点，不是口播对齐。

本包不带示范工程与字体，示范编排只以文字给出。工程运行需要宿主提供 `runtime/gsap.min.js`、`runtime/scene-binding.js`、
所引用的 `stage-full/stage-rig` 与思源黑体 `media/SourceHanSansCN-Regular.otf`。

**动作**：本卡复用 stage-full 的动作包，物体的出现、退场、强调、移动、落定、换场、归位与默认背景（全屏纸板，`panels:2`）的展开、换景、收起，
一律用 [MOTION.md](MOTION.md) 里的动作，不手写缓动；Work 里怎么安装和加载也见那里。下面的示范编排写于动作标准化之前，
机制与分组思路照旧可参考，新作品的动作与背景按 MOTION.md 做。

## 1. 核心原则

- **同一机制，更轻的配置**：`HarnessStageRig.createPaperStage({panels:2})` 只建内板一对（两页式），
  地面桥与道具脚同 full；铰链旋转仍归 rig，位移归 scene wrapper。
- **没有剧场机械**：无台口边框、无吊灯、无 `spot`；强调只用第 3 层一条 `#readbar` 读行。
- **持续对象语义交接**：一个圆形薄荷纸卡从 ② 分组一路留到 ③ 解释，靠从「左簇 → 台中 → 说明位」
  的空间位移完成语义交接，不是整台淡出。
- **分组依据不同**：full 按颜色，light 按形状（圆 3 / 方 3，颜色故意打散），两卡外观明显不同。
- **不是抽象 UI 卡片**：全部为原创内联 SVG/CSS 剪贴，带白边与偏移投影。

## 2. 来源机制（授权提取）

| 来源 | 机制 | 本卡如何用 |
|---|---|---|
| 折叠装置机制 | 四块 480px 墙板、内对 ±86°、外板反向 ±172°、地面桥 -90°、道具脚 88°、先内后外分级展开并锁定、旧景折叠后退、新景在视野里搭起；rig owns 铰链 | 所引用的 `stage-full/stage-rig`，本卡取 `panels:2` 的内板一对 |
| 舞台方向 | 幕布只做开场/收尾、无逐段整幕擦除、不拿整体淡出/平移替代折叠重建 | 纸质封面只在 0.85 升、15.35 落；重建是一次真实折叠 |
| 分层舞台机制 | 微型分层舞台、幕布开场收尾、因果道具交接、剪贴白边 + 偏移投影 | 第 1–4 层、读行、因果指示线、纸卡白边 + 投影 |
| 交错入场机制 | 交错入场与空间对比，用实际动作完成转场 | 六张纸卡交错入场、两格托盘空间对比、折叠完成重建 |

获授权只读提取的机制身份与许可见所引用的 `stage-full/stage-rig` 资产元数据；不配送原作品或私人媒体。

## 4. 阶段分工（Script / Research / Plan / Draft / Export）

- **Script**：本卡不产出；示例无口播、无字幕、无逐字对齐。
- **Research**：本卡不产出；机制来自已授权的只读提取（§2）。
- **Plan**：§3 紧凑表即 Plan。

## 5. 精确资源

所引用资产用 `component install stage-full/<资产>` 装进 Work，精确版本与 SHA-256 由 Work 的 `COMPONENT_LOCK.json` 记录；同版本内容不同时拒绝覆盖。

## 6. 技术检查

- **确定性 seek**：唯一 paused 主时间线注册到 `window.__timelines["<composition-id>"]`，同一条交给
  `HarnessScene.bindScene`；外部 seek 到 t 时直接重建完整状态，`dispose()` 解绑并 kill 时间线。
  无 RAF / play / autoplay / Date / Math.random，不依赖 seek 事件或回调；正放、倒放、随机 seek 一致。
- **字体**：`document.fonts.ready` 就绪后才首次渲染；`@font-face` 只指向 `media/SourceHanSansCN-Regular.otf`，
  `font-display:block`。
- **布局**：固定 1920×1080；第 3 层读行不遮挡第 4 层文字；文字只在阅读窗口内稳定。
- **闭包**：只依赖宿主放好的四个 runtime/media 文件；无图片、音频、字体下载与新依赖；道具与布景为原创内联 SVG/CSS 剪贴。

## 7. 声音与封面

示范编排静音。若某 Variant 需要音效：**只**为结构重击与关键 hit 配音效（如 S4 折叠落定），
**不要**给普通入场自动配音效；音效来自 earshot 音效库渲染、SuperCollider / jsfxr 配方或 HyperFrames 自带音效导入。
配置开启 `bgm.enabled` 时可铺一条开源曲库的现成 BGM（按 `bgm.policy`，`work component import-bgm` 带许可导入），
不用音乐模型或代码合成 BGM。cue 对应同帧可见事件并按 `data-start` 调度，保证 seek 安全。

封面与 stage-full 相同：本卡不规定封面，按工具的封面合同（`.studio/spec/creative.md`）合成。
